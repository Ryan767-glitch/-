# 中小企業向け補助金マッチング（プロトタイプ）

選択式の質問に回答すると、中小企業向け補助金候補をスコア順に表示する静的サイトです。

## 起動方法

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。

## 収録データ

`data/subsidies.json` に補助金データを保持しています。

- IT導入補助金（デジタル化・AI導入補助金2026）
- ものづくり補助金
- 小規模事業者持続化補助金
- 中小企業省力化投資補助金
- 中小企業成長加速化補助金
- jGrants（自治体案件検索用）

## 正確性について

- 最終確認日: **2026-03-26（UTC）**
- 制度名称・対象・公募状況は年度や公募回で更新されます。
- 本サイトは候補抽出を目的にしたプロトタイプです。**申請前に必ず公式公募要領を確認**してください。
